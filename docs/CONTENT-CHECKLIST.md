# Checklist Pengumpulan Konten Resmi

Gunakan daftar ini sebelum website dipublikasikan. Konten contoh pada starter project harus diganti atau dihapus.

## A. Identitas sekolah

- [ ] Nama resmi sekolah sesuai dokumen.
- [ ] Singkatan / nama pendek yang disetujui.
- [ ] Logo dalam format SVG/PNG resolusi memadai.
- [ ] Tagline resmi.
- [ ] Sejarah singkat sekolah.
- [ ] Visi, misi, dan tujuan sekolah.
- [ ] Alamat lengkap dan titik lokasi.
- [ ] Nomor telepon/WhatsApp resmi.
- [ ] Email resmi.
- [ ] Tautan media sosial resmi.
- [ ] Foto gedung, lingkungan, kegiatan, dan fasilitas.

## B. Program keahlian (ulangi untuk PPLG, TJKT, DKV, AKL, dan MPLB)

- [ ] Nama dan kode program terbaru.
- [ ] Deskripsi dan profil singkat.
- [ ] Sejarah pembukaan dan perkembangan program.
- [ ] Visi, misi, dan tujuan program.
- [ ] Nama kepala konsentrasi / ketua program.
- [ ] Daftar guru produktif dan jabatan.
- [ ] Foto guru yang disetujui untuk publikasi.
- [ ] Kurikulum/kompetensi per tingkat kelas yang telah diverifikasi.
- [ ] Daftar fasilitas dan kondisi aktual.
- [ ] Foto fasilitas praktik.
- [ ] Data siswa/rombongan belajar (hanya bila disetujui untuk publikasi).
- [ ] Prestasi beserta bukti, nama, tingkat, dan tahun.
- [ ] Mitra industri dan status kerja sama.
- [ ] Alur dan informasi PKL.
- [ ] Karya siswa beserta izin publikasi.
- [ ] Profil alumni/testimoni beserta persetujuan.
- [ ] Berita program.
- [ ] Foto galeri dengan caption dan tanggal.
- [ ] Kontak program jika berbeda dari kontak sekolah.

## C. Persetujuan dan privasi

- [ ] Foto siswa yang dapat dikenali memiliki izin publikasi dari pihak yang berwenang.
- [ ] Nama, kelas, prestasi, dan karya siswa telah diperiksa.
- [ ] Testimoni alumni mendapat persetujuan eksplisit.
- [ ] Logo/nama mitra digunakan sesuai persetujuan.
- [ ] Tidak ada nomor identitas, alamat pribadi, atau data sensitif.
- [ ] Seluruh konten diperiksa ejaan dan faktanya.

## D. Pemeriksaan teknis sebelum go-live

- [ ] Ganti email contoh `admin@sekolah.example`.
- [ ] Ganti alamat, telepon, dan email placeholder.
- [ ] Ganti seluruh foto contoh dengan foto resmi.
- [ ] Periksa tautan semua CTA.
- [ ] Periksa judul halaman dan deskripsi SEO.
- [ ] Uji tampilan mobile dan desktop.
- [ ] Uji `npm run typecheck` dan `npm run build`.
- [ ] Persetujuan akhir dari penanggung jawab sekolah.
